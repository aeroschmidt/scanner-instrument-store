# CodeQL learning materials

This folder contains learning documentation and screenshots from the [Skills Introduction to CodeQL course](https://github.com/aeroschmidt/skills-introduction-to-codeql). The materials are included here as a reference for studying CodeQL and GitHub code scanning.

> **Important:** The hands-on activities below belong to the course repository. They describe creating and reviewing an intentionally vulnerable example. Do not follow those steps in this scanner repository, and do not copy the course application's source code or workflows here. Perform the exercise only in the separate Skills course repository.

## Learning path

1. [Enable Code Scanning](.github/steps/1-step.md)
2. [Detect vulnerabilities in a pull request](.github/steps/2-step.md)
3. [Review and triage CodeQL alerts](.github/steps/3-step.md)
4. [Fix security vulnerabilities](.github/steps/4-step.md)
5. [Dismissal guidance: triage alerts responsibly](dismissal-guide.md)
6. [Review](.github/steps/x-review.md)

Screenshots from the course are stored in [.github/images](.github/images) and linked locally from the learning steps. Additional dismissal screenshots are labeled as course examples; they illustrate interface locations and are not approval to dismiss alerts in this repository.
