# Guias de segurança para usuários

Material em português para pessoas que criam, revisam, aprovam e fazem merge de Pull Requests. Os guias apresentam a consulta dos alertas, o tratamento dos achados e a confirmação do resultado. A administração das ferramentas e das regras permanece com a equipe mantenedora ou de segurança.

| Guia | Leitura no GitHub | Arquivo Word |
| --- | --- | --- |
| Code Scanning | [Abrir guia](guia-usuario-code-scanning.md) | [Baixar Word](guia-usuario-code-scanning.docx) |
| Dependabot | [Abrir guia](guia-usuario-dependabot.md) | [Baixar Word](guia-usuario-dependabot.docx) |
| Secret Scanning | [Abrir guia](guia-usuario-secret-scanning.md) | [Baixar Word](guia-usuario-secret-scanning.docx) |

As palavras-chave dos guias levam à documentação oficial. As capturas são exemplos históricos de treinamento e não comprovam o estado atual das configurações da empresa. Valores de credenciais nas capturas de AWS e MongoDB foram ocultados para distribuição.

Os alertas e as verificações de compilação ou testes são resultados diferentes. A possibilidade de merge continua sujeita às regras e aprovações de cada repositório.
